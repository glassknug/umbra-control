Umbra Control for Linux — 0.4.0 RGB layout preview
Project by glassknug

Quit the currently running app first. Extract all files together.
To test directly, open a terminal in this folder and run:
python3 asiahorse_gui.py

Open RGB layout. Drag Fan, LED strip or ARGB cable into the case.
Assign its physical hub port, color and effect. Use Apply layout RGB.
Unassigned hub ports turn dark. Save layout preserves your design.
Devices sharing a port share its effect. Separate USB cable controllers
and individual fan motor duty are not supported by this feature.

README.md covers Tk, USB permissions, known limitations and original credits.
To install the menu launcher later, run without sudo:
python3 install_desktop.py
